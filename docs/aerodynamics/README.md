# Aerodynamics Theory and Implementation

## Overview

This document covers the aerodynamic principles underlying the BGKPJR launch system, specifically the Gryphon lifting body spacecraft design.

## Flight Regimes

The Gryphon operates across four distinct aerodynamic regimes:

### 1. Subsonic (M < 0.8)
- Standard incompressible flow equations apply
- Lift: `L = 0.5 * ρ * V² * S * C_L`
- Drag: `D = 0.5 * ρ * V² * S * C_D`

### 2. Transonic (0.8 < M < 1.2)
- **Prandtl-Glauert Correction** for compressibility:
  ```
  C_L,comp = C_L,0 / sqrt(1 - M²)
  ```
- Wave drag rise near Mach 1
- Critical design point for structural loads

### 3. Supersonic (1.2 < M < 5)
- **Ackeret Linear Theory**:
  ```
  C_L = 4α / sqrt(M² - 1)
  C_D,wave = 4α² / sqrt(M² - 1) + 4(t/c)² / sqrt(M² - 1)
  ```
- Primary operating regime for atmospheric ascent

### 4. Hypersonic (M > 5)
- **Modified Newtonian Theory**:
  ```
  C_L = C_p,max * sin²(α) * cos(α)
  C_D = C_p,max * sin³(α) + C_D0
  ```
  where `C_p,max ≈ 1.84` for γ = 1.4

## Gryphon Aerodynamic Design

### Blended Wing Body Configuration
- Low aspect ratio (AR ≈ 2.5) for hypersonic stability
- Variable geometry wings (retracted in tube, deployed for atmospheric flight)
- Stealth-inspired faceted surfaces for predictable flow characteristics

### Key Aerodynamic Parameters
| Parameter | Value | Notes |
|-----------|-------|-------|
| Reference Area (deployed) | 120 m² | Wing planform area |
| Reference Area (retracted) | 40 m² | Body cross-section |
| Zero-lift drag (C_D0) | 0.015 | Hypersonic regime |
| Lift curve slope | 0.05/deg | Linear region |
| L/D (hypersonic) | 4.5 | Design point |
| L/D (subsonic) | 8.0 | Glide return |

### Induced Drag
Drag due to lift calculated using:
```
C_D,induced = C_L² / (π * AR * e)
```
where `e ≈ 0.8` (Oswald efficiency factor for lifting body)

## The "Skipping Stone" Revisited

### Subsonic Flight
At subsonic speeds, the "skipping stone" analogy is **incorrect**. Lift is generated by pressure differences due to flow acceleration over curved surfaces (Bernoulli principle).

### Hypersonic Re-entry
However, at hypersonic speeds (M > 5), the **Newtonian impact theory** (basis of skipping stone) becomes increasingly accurate. Air molecules effectively "bounce" off the lower surface, transferring momentum directly.

**Design Implication:** Our simulation uses a **Hybrid Physics Solver**:
- Low altitude/speed: Navier-Stokes / Bernoulli
- High altitude/speed: Newtonian impact theory
- Smooth transition in the transitional regime

## Reynolds Number Effects

```
Re = ρ * V * L / μ
```

Critical for:
- Boundary layer transition (laminar → turbulent)
- Skin friction drag
- Flow separation characteristics

**Gryphon Design Point:**
- At Mach 3.5, sea level: Re ≈ 10⁸ (fully turbulent)
- At 50 km altitude: Re ≈ 10⁶ (transitional)
